Sandbox Wallet

A carteira que usa máscaras. Quem fala com o site é uma máscara com orçamento limitado. A carteira principal nunca aparece.

Ver a demonstração ao vivo Código no GitHub

O problema

Todo golpe de "aprovação" funciona do mesmo jeito: um site pede uma assinatura inocente ("resgatar airdrop", "aprovar para continuar") e a assinatura dá ao golpista o poder de mover tudo que está na carteira conectada. As carteiras de hoje conectam a carteira inteira ao site. Os simuladores avisam antes de assinar, mas o aviso é ignorado, e um site golpe bem feito engana a simulação. Em Solana nem existe "aprovação": a própria transação assinada pode levar qualquer token da conta.

A solução

Nunca conectar a carteira principal. Para cada site, a carteira deriva uma máscara: um endereço calculado a partir da mesma frase de recuperação e do nome do site. A máscara recebe só o orçamento que você definiu para aquela sessão. O site conecta, aprova, assina e opera com a máscara. O resultado volta direto para a principal. No fim, as sobras são varridas de volta.

Carteira comum

Site golpe pede aprovação → usuário assina → golpista leva 100% da carteira.

Sandbox Wallet

Site golpe pede aprovação → usuário assina → golpista leva só o orçamento da máscara. A principal não existe para ele.

Para quem

Para qualquer pessoa que conecta a carteira em sites: quem usa DeFi, quem resgata airdrops, quem joga, quem compra NFT. Especialmente para quem está começando e ainda assina sem ler. E para carteiras que queiram adotar o modelo: o site não precisa mudar nada, a máscara é uma carteira comum para ele.

Como funciona por dentro

  • Derivação: índice = primeiros 4 bytes de sha256("sandbox-wallet/v1/" + site + "/" + rotação). EVM: m/44'/60'/1'/0/índice. Solana: m/44'/501'/índice'/1'. Mesma frase, caminhos que nenhuma outra carteira usa.
  • Recuperável: frase + nome do site recriam a máscara em qualquer lugar. "Trocar de máscara" é subir a rotação.
  • Orçamento: abastecimento numa transação (Solana) ou em lote (EVM). O site nunca alcança mais que isso.
  • Varredura: devolve tokens e moeda à principal; em Solana fecha as contas e recupera o aluguel, então o custo líquido é quase só a taxa de rede.
  • Redes: Solana e todas as EVM (BSC, Ethereum, Polygon, Arbitrum, Base) com o mesmo código.

A demonstração

  1. Crie uma carteira de demonstração (uma tesouraria de teste deposita moeda e 1000 USDX de brinquedo).
  2. Um site golpe ("airdrop grátis") pede para conectar. Escolha a máscara, ou a carteira principal para ver o que acontece hoje.
  3. Assine sem ler. O golpista drena a conta conectada.
  4. Veja os saldos: com a máscara, a principal continua intacta.
